## Portal

Welcome. Markpedia is written in Markdown and its articles are organized under the classic
nine fields **天 地 文 法 商 理 工 醫 農**
(Astronomy, Earth, Humanities, Law, Business, Science, Engineering, Medicine, Agriculture),
each with subcategories at the next level.

## The nine fields

| Field | Scope |
| --- | --- |
| [天](#/p/cat-tian) | Astronomy, space, weather |
| [地](#/p/cat-di) | Earth, ocean, geography |
| [文](#/p/cat-wen) | Literature, history, philosophy, languages |
| [法](#/p/cat-fa) | Law, politics, institutions |
| [商](#/p/cat-shang) | Economics, management, finance |
| [理](#/p/cat-li) | Mathematics, physics, chemistry |
| [工](#/p/cat-gong) | Software, mechanical, electrical |
| [醫](#/p/cat-yi) | Medicine, public health, nutrition |
| [農](#/p/cat-nong) | Agriculture, biology |

## How to contribute

Use 新增 (create) to start an article, file it under the right subcategory,
and remember the spacing rule for inline math: spaces around $E = mc^2$.
