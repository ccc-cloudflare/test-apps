    這個翻譯器怎麼運作

    翻譯完全在瀏覽器中進行，不會把文章送到任何伺服器。

    中文 ⇄ Mini-Lang 依規則翻譯。中文 → Mini-Lang 依序做：

    1. 中文數字換成阿拉伯數字（二十二歲 → 22歲）。
    2. 數字後的量詞換成「個」（一隻狗 → 一個狗）。
    3. 查詞典換詞（醫院 → 看病的地方、狗 → dog），英文外來語第一次出現時加上說明。
    4. 需要改寫句子結構的詞（雖然、已經…）不自動換，只標出來並給建議。

    英文用瀏覽器內建的翻譯模型（桌面版 Chrome 138 以上），第一次使用時要先下載模型，之後在本機執行。英文和 Mini-Lang 之間經過中文：Mini-Lang → 中文 → English、English → 中文 → Mini-Lang。

    依規則的翻譯：結果通常還要人讀一次、改通順。完整規則見 universal.md，範例見 examples.md。
